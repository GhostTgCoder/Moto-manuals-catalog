Русскоязычный комплект для ultimate-motorcycle-manual-archive

Состав:
- README.md — основной README на русском языке;
- DESCRIPTION_RU.md — краткое и расширенное описание для GitHub;
- ABOUT_RU.md — описание проекта;
- PROMO_RU.md — готовые промопосты и CTA;
- SEO_RU.md — поисковые фразы и шаблоны запросов;
- CONTRIBUTING_RU.md — правила предложений и исправлений;
- DISCLAIMER_RU.md — предупреждение об использовании документации;
- REPOSITORY_TOPICS_RU.txt — предлагаемые темы/теги GitHub.

Числа 300+ марок и 22 000+ документов отражают заявленные данные проекта и перед публикацией должны соответствовать актуальному состоянию каталога.
Этот комплект содержит документацию и промоматериалы, а не исходный код архива или Telegram-бота.
