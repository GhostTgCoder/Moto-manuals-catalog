# Русскоязычная SEO-структура

## Основные поисковые фразы

- мануалы для мотоциклов
- руководство по эксплуатации мотоцикла
- сервисный мануал мотоцикла
- руководство по ремонту мотоцикла
- техническая документация для мотоциклов
- каталог мануалов для мототехники
- мануалы для электромотоциклов
- мануалы для скутеров
- мануалы для электроскутеров
- руководство для квадроцикла
- сервисный мануал ATV
- руководство для UTV
- мануал для багги
- документация для картинга
- руководство для трицикла
- мануал для лодочного мотора
- инструкции по обслуживанию мототехники

## Шаблоны запросов по марке и модели

Используйте только реальные марки и модели, присутствующие в каталоге:

- `[марка] мануал`
- `[марка] руководство по эксплуатации`
- `[марка] сервисный мануал`
- `[марка] руководство по ремонту`
- `[марка] [модель] мануал`
- `[марка] [модель] сервисный мануал`
- `[марка] [модель] руководство по эксплуатации`
- `[марка] [модель] ремонтная документация`

## Англоязычные запросы, полезные для поиска

В международной документации часто используются термины:

- motorcycle owner's manual
- motorcycle service manual
- motorcycle repair manual
- workshop manual
- scooter service manual
- ATV service manual
- UTV owner's manual
- outboard motor service manual

## Принцип точности

Не добавляйте к SEO-описаниям марки, модели, годы выпуска или типы документов, наличие которых не подтверждено каталогом. Не обещайте, что для каждой модели доступен полный комплект документов.
