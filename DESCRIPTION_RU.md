# Краткое описание репозитория

**Название:** Ultimate Motorcycle Manual Archive

**Краткое описание для GitHub (RU):**
Большой архив руководств и технической документации для мотоциклов, электромотоциклов, скутеров, квадроциклов, ATV/UTV, багги, картинга, трициклов и лодочных моторов. По данным проекта — 300+ марок и 22 000+ документов.

**Расширенное описание:**
Ultimate Motorcycle Manual Archive помогает искать руководства по эксплуатации, сервисные мануалы, ремонтную документацию и технические материалы для широкого спектра мототехники и смежных категорий транспорта. Каталог проекта связан с Telegram-сообществом [@motodocs](https://t.me/motodocs).

**Рекомендуемая строка для поля About на GitHub:**
Архив мануалов и сервисной документации для мототехники: 300+ марок, 22 000+ документов. Мотоциклы, скутеры, ATV/UTV, багги и другая техника.

**Вариант для русскоязычного промо:**
Ищете мануал для мотоцикла или другой техники? Ultimate Motorcycle Manual Archive собирает руководства по эксплуатации, сервисную и техническую документацию по множеству марок и категорий транспорта. Каталог: @motodocs.
